# DINE AI — оқу жобасы

Бұл — DINE AI мейрамхана сайтының React + Node.js негізіндегі оқу нұсқасы. Жаңа нұсқада DARK 3D EXPERIENCE визуалды стилі, қызғылт-сары жарық эффектілері, қалқымалы hero-көрініс, hover және scroll reveal анимациялары қосылған.
Жоба үш тілде жұмыс істейді: қазақша, орысша, ағылшынша.

## 1. Қажет бағдарламалар
- Node.js (LTS): https://nodejs.org/
- Visual Studio Code: https://code.visualstudio.com/

## 2. Жобаны ашу
1. `DINE-AI` папкасын компьютерге шығарыңыз.
2. VS Code ашыңыз.
3. File → Open Folder арқылы `DINE-AI` папкасын таңдаңыз.
4. Terminal → New Terminal ашыңыз.
5. Мына команданы орындаңыз:

```bash
npm install
```

6. Содан кейін:

```bash
npm run dev
```

7. Браузерде көрсетілген Vite адресін ашыңыз (әдетте http://localhost:5173).

## 3. AI режимін қосу
Жоба API кілтінсіз де демо режимінде жұмыс істейді. Чат мәзірдегі тағамдар туралы қарапайым сұрақтарға жауап береді, ұсыныстар мәзір деректеріне сүйенеді.

Нақты AI моделін қосқыңыз келсе:
1. `.env.example` файлын `.env` деп көшіріңіз.
2. `.env` ішіндегі `OPENAI_API_KEY` мәніне өз API кілтіңізді енгізіңіз.
3. Серверді қайта іске қосыңыз.

API кілтін ешқашан `src/` ішіне немесе браузерге көрінетін кодқа жазбаңыз. `.env` файлы GitHub-қа жүктелмеуі керек.
Нақты AI API қолдану ақылы болуы мүмкін. Кілт болмаса, демо режимі қолжетімді.

## 4. Файлдардың міндеті
- `src/App.jsx` — сайттың интерфейсі, тіл ауыстыру, чат, мәзір, себет, брондау.
- `src/styles.css` — DARK 3D EXPERIENCE дизайны, анимациялар және мобильді бейімдеу.
- `server/index.js` — API сервері, чат, ұсыныс, мәзірді талдау, брондау endpoint-тері.
- `server/menu.js` — мәзір деректері.
- `vite.config.js` — frontend пен backend арасындағы жергілікті proxy.
- `.env.example` — сервер құпиясөздерін сақтауға арналған үлгі.

## 5. Қорғауда дұрыс айту
- API кілтін қоспай тұрған кезде сайт демо режимінде жұмыс істейді.
- AI API кілті қосылған кезде чат пен мәзірді талдау сыртқы AI моделіне сұраныс жібереді.
- Тағам ұсынысы әзірге мәзір деректерін сүзу логикасымен жасалады; оны кейін AI моделіне толық тапсыруға болады.
- Брондау формасы әзірге демонстрациялық: дерекқорға тұрақты сақтамайды.
- Бұл оқу прототипі, нақты ресторанның төлем және брондау жүйесі емес.
